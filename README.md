# Majemu Olowodola — Portfolio

**Live site:** `index.html` at the root — a fully self-contained page (fonts and scripts inlined, photos served from Cloudinary). Netlify serves this directly; no build step needed.

**`nextjs-source/`** — the full Next.js + TypeScript codebase for future development. See `nextjs-source/README.md` for setup, Cloudinary wiring, and deployment notes.

To update the live site: edit or replace `index.html` and push. Netlify redeploys automatically.
